# Prompt library — starter ideas for practice

Use these as editable examples; write your own version with the prompt recipe before copying.

## Copilot Chat

- **L01:** List three tasks from the manager assignment and one question I should ask. Then: Order these by what a new trainee can safely do first.
- **L03:** What is clear and unclear in this manager request? Then: Put assumptions in a separate section and ask three questions.
- **L04:** Write a short internal email requesting an onboarding status update. Then: Apply the CBB communication style guide and set a calm tone.
- **L06:** Help me construct an escalation prompt using the attached approved policy and fictional case details. Then: Ask for confirmed facts, missing facts, a draft and an approval gate.

## Word

- **L10:** Draft a warm onboarding welcome letter using this brief. Then: Use headings and a short next-steps list in plain language.
- **L11:** Review this broken onboarding procedure. Then: Rewrite it with a clear owner, approval step and exceptions.
- **L12:** Create an SOP outline based on these documents. Then: Use only approved rules and list draft conflicts as open issues.

## Outlook

- **L13:** Draft a short internal email requesting an update. Then: Make it more concise while retaining the request and context.
- **L14:** Summarise the actions in this training email thread. Then: Separate confirmed owners and deadlines from proposed dates.
- **L15:** Draft an acknowledgement of this fictional customer concern. Then: Remove promises of approval; add a manager approval request.

## OneDrive

- **L16:** Summarise the selected approved onboarding policy file. Then: Include policy version and effective date in the first line.
- **L17:** Compare these two policy files. Then: Show changed target, status and applicability as a table.
- **L18:** Which of these selected documents is safe to cite externally? Then: Build a source authority table and flag internal-only material.

## Teams

- **L19:** Summarise the main actions and decisions from this meeting. Then: Separate proposals from confirmed decisions.
- **L20:** List the owners and dates from this operations meeting. Then: Include dependency and needs-confirmation columns.
- **L21:** Compare the meeting recap with the transcript. Then: Make a correction log and cite the relevant transcript passage.

## Excel

- **L22:** Explain this synthetic onboarding table to a beginner. Then: List the date columns and possible data quality concerns.
- **L23:** Help me compare branch performance fairly. Then: Calculate late percentages only for eligible completed cases.
- **L24:** Find data-quality problems affecting this branch late-rate report. Then: Group duplicate IDs, open cases, missing dates and invalid chronology.

## PowerPoint

- **L25:** Outline four slides for an onboarding improvement update. Then: Make each slide headline a decision-relevant statement.
- **L26:** Draft an executive deck from this verified branch analysis. Then: Add a caveat about excluded records and cite source workbook.
- **L27:** Review this executive draft for unsupported claims. Then: Rewrite the KPI headline using only verifiable comparisons.

## Notebooks / planning

- **L28:** Prioritise these banking operations tasks for a new trainee. Then: Separate can-do-now, ask-manager and needs-approval.
- **L29:** Build a small action plan from the seeded meeting register. Then: Show milestones, owners, dependencies and open questions.
- **L30:** Create a grounded project brief from these selected references. Then: Label facts, draft proposals and unanswered questions separately.

## When it is wrong

Stop. Reopen the source, compare the date and approval status, ask for the evidence, and correct the result manually. Escalate to the appropriate employee before publishing.
