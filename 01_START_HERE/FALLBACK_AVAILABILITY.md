# If you are missing an earlier output

Most labs can start from their own source files. Four later labs also permit a trainer-provided recovery file. The recovery files are **not** distributed with the learner package because they contain completed example calculations or action registers.

| Lab to continue | Earlier work | Ask the trainer for |
|---|---|---|
| L26 | L23 branch analysis | `L23_Branch_Analysis_FALLBACK.xlsx` |
| L27 | L24 verified KPI analysis | `L24_Verified_KPI_Analysis_FALLBACK.xlsx` |
| L29 | L20 meeting action register | `L20_Action_Register_FALLBACK.md` |
| L30 | L20 meeting action register | `L20_Action_Register_FALLBACK.md` |

Ask the trainer privately, use only the supplied file for the lab you are completing, and label the completed submission as using a trainer-provided fallback. Do not share the file with classmates before they complete the originating activity.
