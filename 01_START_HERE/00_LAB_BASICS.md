# Lab basics — Read once before beginning

## Sign in and protect your working files

1. Turn on your laptop and connect to EIF's approved network.
2. Open the Microsoft 365 work app using the account provided for training. Your trainer must confirm the available Copilot controls.
3. Open the `03_SYNTHETIC_RESOURCES` folder. These files describe **Crescent Bay Bank**, a fictional bank; none are actual rules or customer records.
4. Before editing any Office file, make a personal copy in the learner's assigned `My_Work` area.
5. Start a new chat for independent tasks. When using Copilot, share only the supplied synthetic files.
6. Review all generated claims against their sources. Do not send training emails to external recipients or assume a draft is approved.
7. Name your saved file `Lnn_My_Work` and show it to the trainer at the lab checkpoint.

## If Copilot is unavailable

Tell the trainer which feature is missing. Use the lab's original file or labelled fallback for **offline practice**. Do not report it as a successful live Copilot exercise. Unsupported controls are not a learner mistake.

## When an answer looks wrong

Check the original source, ask what evidence supports the statement, correct the draft, and request human approval before any release. Read the short `PROMPT_RECIPE.md` and `RESPONSIBLE_AI_CHECKLIST.md`.
