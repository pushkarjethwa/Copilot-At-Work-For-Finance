## Prompt practice for weak prompt versus structured prompt

1. **Starter:** “Write a short internal email requesting an onboarding status update.” Enter this with the synthetic document open; replace any names in brackets with facts from the named source.
2. **Improve:** “Apply the CBB communication style guide and set a calm tone.” Compare the second response with the first, retaining your own prompt edits.
3. **Check:** “Did you invent an approval date or customer identity?” Do a manual source check before accepting the response.
