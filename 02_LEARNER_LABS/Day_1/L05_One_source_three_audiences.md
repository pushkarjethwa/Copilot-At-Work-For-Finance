## Prompt practice for one source, three audiences

1. **Starter:** “Summarise these same policy facts for three audiences.” Enter this with the synthetic document open; replace any names in brackets with facts from the named source.
2. **Improve:** “Use a table showing the same facts in all versions.” Compare the second response with the first, retaining your own prompt edits.
3. **Check:** “What fact changes between versions? It should be none.” Do a manual source check before accepting the response.
