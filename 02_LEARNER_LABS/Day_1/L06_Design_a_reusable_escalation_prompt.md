## Prompt practice for design a reusable escalation prompt

1. **Starter:** “Help me construct an escalation prompt using the attached approved policy and fictional case details.” Enter this with the synthetic document open; replace any names in brackets with facts from the named source.
2. **Improve:** “Ask for confirmed facts, missing facts, a draft and an approval gate.” Compare the second response with the first, retaining your own prompt edits.
3. **Check:** “If a detail is absent, what should we write instead of guessing?” Do a manual source check before accepting the response.
