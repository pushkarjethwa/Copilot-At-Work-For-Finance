## Prompt practice for evidence triangulation with an unapproved faq

1. **Starter:** “Compare the approved policy with this draft FAQ.” Enter this with the synthetic document open; replace any names in brackets with facts from the named source.
2. **Improve:** “Mark statements as supported, unsupported or pending approval.” Compare the second response with the first, retaining your own prompt edits.
3. **Check:** “Which FAQ claim would be unsafe to publish?” Do a manual source check before accepting the response.

## Inspect a successful evidence triangulation with an unapproved faq result

A concise result makes an authority decision table and one corrected FAQ answer easy to inspect. Open the FAQ draft status and compare it with the approved-policy header. This is a format example, not a substitute for doing the activity.
