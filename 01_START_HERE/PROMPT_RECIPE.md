# Your prompt recipe — Goal • Context • Source • Format • Check

| Element | Beginner question | Example |
|---|---|---|
| Goal | What do I need? | Summarise a fictional customer onboarding policy |
| Context | Who will read it? | For a new retail operations trainee |
| Source | Which file is authoritative? | Use the approved CBB policy, not the draft FAQ |
| Format | What form helps most? | Five short bullets and an unanswered-questions list |
| Check | How will I verify it? | Include source section names; leave unknowns blank |

**Write your first draft** before looking at the lab's starter prompt. Compare the two. A specific, verifiable prompt is better than a long prompt.

**Reusable skeleton:** “Using [name of the provided file], help me [task] for [audience]. Return [format]. Mark missing facts as unknown. Do not make approval promises. I will check each claim against the source.”

**Improve it:** “Make the key action clear, separate facts and assumptions, and cite the relevant source section.”

**Check it:** “Which statements cannot be verified in the supplied file?”

**Five-second check:** Right source? Correct audience? Clear output? No invented detail? Human release gate?
