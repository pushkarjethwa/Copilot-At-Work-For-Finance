# Instructor: seed mailbox content

> These `.eml` files are **source messages**, not proof that Exchange Online mailboxes are configured. Microsoft Copilot in Outlook cannot be reliably tested against local file previews.

1. Create or designate a permitted synthetic training mailbox for each learner/group.
2. Send the message texts in the intended thread order using *real accessible training accounts*, changing sender identities to training identities as required.
3. Use **Reply** to preserve real conversation threading for email 01–04 and 05–08 rather than uploading disconnected `.eml` files.
4. Check permissions, supported mailbox type and the participant's licence.
5. As a learner-equivalent user, open Outlook; verify **Summarize** / draft assistance works for each genuine conversation.
6. Reset between cohorts by removing previous learner replies and recreating the two seeded threads.

`.example` addresses are fictional placeholders and cannot be used as live email destinations. Never send training messages to real customers.
