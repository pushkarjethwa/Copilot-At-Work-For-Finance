## Prompt practice for decide which guidance can be shared

1. **Starter:** “Which of these selected documents is safe to cite externally?” Enter this with the synthetic document open; replace any names in brackets with facts from the named source.
2. **Improve:** “Build a source authority table and flag internal-only material.” Compare the second response with the first, retaining your own prompt edits.
3. **Check:** “Which item lacks approval or sharing permission?” Do a manual source check before accepting the response.
