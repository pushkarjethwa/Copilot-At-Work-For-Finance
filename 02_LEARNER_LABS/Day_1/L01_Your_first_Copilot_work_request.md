# L01 — Your first Copilot work request

**Goal:** Turn a broad request into a short, useful work plan.  
**Time:** 5 minutes (1 + 2 + 2).    
**Scenario:** A manager has asked for an onboarding review, but the request is not yet a complete plan. All cases, customers and data are synthetic.

Check the shared Lab Basics page before handling three practical next actions plus one question about the assignment; use the Prompt Recipe if the response lacks evidence. Save only to your individual training folder.

## Prompt practice for your first copilot work request

1. **Starter:** “List three tasks from the manager assignment and one question I should ask.” Enter this with the synthetic document open; replace any names in brackets with facts from the named source.
2. **Improve:** “Order these by what a new trainee can safely do first.” Compare the second response with the first, retaining your own prompt edits.
3. **Check:** “Which deadline did the source actually confirm?” Do a manual source check before accepting the response.
