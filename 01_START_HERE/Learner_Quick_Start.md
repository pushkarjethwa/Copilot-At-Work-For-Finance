# Copilot at Work — learner quick start (V4.1)

**Crescent Bay Bank:** fictional scenario, synthetic documents and data. Audience: early-career banking staff. No coding.

**Core schedule:** Day 1 = 480 minutes (L01–L18). Day 2 = 330 minutes (L19–L30). Total = **13.5 instructional hours**. Optional L31–L34 are not part of your core learner ZIP.

1. Read `00_LAB_BASICS.md`, `PROMPT_RECIPE.md` and `RESPONSIBLE_AI_CHECKLIST.md`.
2. Check the trainer's Day-0 account/app checklist; never assume a tenant feature is enabled.
3. Open the lab for the current module in `02_LEARNER_LABS/Day_1` or `Day_2`.
4. Use only `03_SYNTHETIC_RESOURCES`. If a lab needs an earlier product, use its named `FALLBACK` after trying independently.
5. Record Starter → Improve → Check prompts and save with the lab ID.
6. Use the feedback/assessment form after Day 1 and the final assessment after Day 2.

**Important:** Live Outlook, Teams and Notebooks require training-tenant configuration. Local sample files are preparation/fallback materials, not proof those features are working.


**V4.1 fallback distribution:** Completed L20/L23/L24 recovery files are held in `TRAINER_PACK/FALLBACK_ON_DEMAND/` and provided only on learner request. Learners see file names in `01_START_HERE/FALLBACK_AVAILABILITY.md`, not the solution files. Record each transfer in the trainer assistance log. The Copilot application and tenant capabilities remain **Not tested** until the actual EIF pilot.
